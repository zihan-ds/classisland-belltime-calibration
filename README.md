# 铃声自动校时（BellTime Calibration）

监听校园广播铃声，自动把 [ClassIsland](https://github.com/ClassIsland/ClassIsland) 的
**应用设置 → 时钟 → 时间偏移**校准到学校广播铃钟的 2.x 插件。
**不改课表、不改内核**，原版内核即可运行。

| 项 | 值 |
|---|---|
| 插件 ID | `belltime.calibration` |
| 版本 | **1.0.4** |
| apiVersion | 2.0.0.0（ClassIsland 2.x） |
| 平台 | Windows（需要可用的默认输入设备） |
| 许可 | GPL-3.0-only（见 [`LICENSE`](LICENSE)） |
| 作者 | zihan_ds（GitHub：[@zihan-ds](https://github.com/zihan-ds)） |

---

## 它做什么

学校铃声不一定和电脑时钟对齐，而 ClassIsland 依据本机时间切换上下课。
本插件在每个课表边界附近**短暂开麦**，听取真实校铃的起响时刻，据此推算应有的时间偏移——
校准语义是「**跟随学校广播铃钟**」。

**安全默认**：装好后处于**学习模式**，只记录识别结果，不写任何设置。确认误差合理后再开自动应用。

---

## 安装

**应用内（推荐）**：ClassIsland **2.x** →「设置 → 插件」→ 搜索「铃声自动校时」安装。

**手动**：从 [Releases](https://github.com/zihan-ds/classisland-belltime-calibration/releases) 下载
`BellTimeCalibration.cipx`，拖入「设置 → 插件」页面。首次使用需在系统设置中授予 ClassIsland **麦克风权限**。

---

## 先别急着开启自动应用

1. 安装后**保持学习模式**，正常使用几天。
2. 每次识别到铃声，日志会记录起响时刻与误差 `delta`。
3. 核对：对齐良好时 `delta` 趋近 0；稳定为一个非零值说明本机与校铃存在固有偏差，该值就是要写入的偏移；
   忽大忽小多半是环境误检。
4. 确认合理后，在插件设置页**关闭学习模式**，再开启**自动应用校准偏移**。

---

## 铃声样本（建议录制）

主判据「起响沿闸门」**不依赖样本**，装好即可工作；样本只用于辅助的模板匹配路径，
在个别窗口能把起响点精确到毫秒级。**本仓库不含任何录音**，随包的 `Templates/` 两个 `.wav` 是静音占位。

录制要点：

- 用**装 ClassIsland 那台电脑的麦克风**，在真实响铃时录，开头多留 5~10 秒环境声更好；
- 上课铃、下课铃**各录一段**（两者音色差别很大，不可混用）；保存为 WAV，`.m4a`/`.mp3` 请先转成 WAV。

导入（任选其一）：

- **设置页导入（推荐）**：「设置 → 插件 → 铃声自动校时 → 模板匹配（铃声样本）」点「浏览…」选中录音；
  需要时填「截取区间」（如 `12.0-14.5`，留空 = 自动取最响且持续 ≥1.5 s 的段）。**选完立即生效**，无需重启。
- **直接放文件**：把截好的 2.5 s 模板放到插件配置目录 `Templates/` 下，文件名含「上课」/「下课」，重启 ClassIsland。

验证样本是否可用：

```powershell
# 用生产匹配器在录音上自测，同源应接近 1.000
TemplateTool selftest plugin/Templates/上课铃.wav 你的录音.wav 0.6 0.45 15
```

## 主要设置

设置页可改，持久化于 `BellCalibrationSettings.json`（改动即自动保存）。

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用铃声自动校时 | 开 | 总开关，关闭后不监听也不应用 |
| 学习模式 | **开** | 只记录识别结果，不应用偏移 |
| 自动应用校准偏移 | 关 | 需先关闭学习模式 |
| 布防提前秒数 / 边界后监听秒数 | 15 / 8 | 窗口期的长度 |
| 应用死区（秒） | 0.3 | 估计值与当前偏移之差小于此值就不动，避免跟着抖动反复微调 |
| 大误差复核阈值（秒） | 3 | 一次要改的偏移超过此值时**拒绝写入**并弹出人工复核提醒（1~120 s） |
| 人工审核提醒 | 开 | 关掉后大误差**仍然拒写**，只是不再弹提醒（只记日志） |
| 忽略的边界时刻 | 空 | **留空 = 每个边界都监听**；某几个边界反复测不到时再按 `HH:mm` 填入 |
| 识别灵敏度 | 2.0 | 突发能量须超过环境噪声底的倍数 |

完整设置项（含模板匹配阈值等）见 [`plugin/README.md`](plugin/README.md)。

## 隐私

- **绝不常驻监听**：麦克风只在「布防提前秒数 + 边界后监听秒数」的窗口期内启用，其余时间零占用。
- **绝不落盘**：音频只做内存统计；仅在显式开启调试转存时才会写出 WAV。
- 麦克风被占用 / 无设备 / 无权限时优雅跳过本窗口并记日志，不影响 ClassIsland 其它功能。

---

## 已知限制

- **校铃自身抖动是误差下限**：同一批边界的「所需偏移」实测可差 ±1.5 s，因此单一偏移量无法让每个边界都落进 ±0.5 s；
  本插件的目标是**中位误差最小且误差不累积**。
- **吵闹窗口不校准**：噪声底高于约 −25 dBFS 时闸门命中率明显下降，这些边界记为「无可信测量」并跳过。
- **一天内不同时段的最优偏移可能不同**（实测上午与晚上差 3 s 以上），因此估计器用 6 小时窗口，
  并只在残差足够小（<0.3 s）时才启用趋势外推。
- 需要麦克风与 Windows；无设备或无权限时只记录、不校准。
